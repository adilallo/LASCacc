# Non-Playable

## Required Assets

This project requires the following Unity Asset Store package to run properly:

### FronkonGames - Artistic TiltShift

**Note:** Due to DMCA compliance, the FronkonGames Artistic TiltShift package is not included in this repository. You will need to download and install it separately.

**To install:**
1. Purchase/download the [Artistic TiltShift](https://assetstore.unity.com/packages/vfx/shaders/fullscreen-camera-effects/artistic-tiltshift-245158) package from the Unity Asset Store
2. Import the package into your Unity project
3. Place it in `Assets/FronkonGames/` directory

The package is required for the tilt-shift camera effect used in this project.

## Setup

1. Clone this repository
2. Open the project in Unity
3. Install the required FronkonGames Artistic TiltShift package (see above)
4. The project should now be ready to use
